# Changelog

## 1.0.2

- Add a 128x128 extension icon for the Marketplace and VS Code extension list.

## 1.0.1

- Rename the extension to **Quick Log: Console Shortcuts**.

## 1.0.0

- Insert `console.log` using a keyboard shortcut.
- Use the selection or the variable at the cursor as the logged expression.
- Customize the prefix and message template through VS Code settings.
- Preserve indentation and line endings, with each insertion available as one undo step.
